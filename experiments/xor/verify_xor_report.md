## (a) Interaction criterion

**Derivation.** The skip score s = v₁x₁ + v₂x₂ + c ranges over exactly the additive patterns on the four rows, a 3-dimensional space. Its orthogonal complement in ℝ⁴ is spanned by e = (1, −1, −1, 1), so e·s = 0 for every skip setting, and e·h = I. Because t = −e,

  Σᵣ tᵣ zᵣ = −e·s − u e·h = −u I.

If every row has margin m, the left side is at least 4m, so **u I ≤ −4m**: I ≠ 0, u has the opposite sign to I, and **|u| ≥ 4m/|I|**. Conversely, if u I ≤ −4m, take the skips s = −(u h − (u I/4) e), which is additive because it is u h minus its own component along e. Then z = (u I/4) e and every row has margin −u I/4 ≥ m. So the bound is exact, not approximate: with unit margin, |u| ≥ 4/|I|, with equality only for the equal-margin readout. It holds for any activation, because h enters only through its four values. Under strict sign, XOR is solvable iff I ≠ 0 (any u with u I < 0 works).

## (b) ReLU: sign(I) = sign(w₁w₂)

**Derivation.** a₀₀ + a₁₁ = a₁₀ + a₀₁ = 2b + w₁ + w₂, so the pairs {00, 11} and {10, 01} have the same midpoint m = a(½, ½), with half-spreads |w₁ + w₂|/2 and |w₁ − w₂|/2. For convex φ, φ(m + d) + φ(m − d) is non-decreasing in d, so the pair with the larger spread has the larger sum. |w₁ + w₂| > |w₁ − w₂| iff w₁w₂ > 0, so sign(I) = sign(w₁w₂) or I = 0. For ReLU the sum is strictly increasing once the pair straddles the fold, and if the wider pair does not straddle it, neither does the narrower one, so all four rows sit on one side of the fold. Hence I ≠ 0 exactly when w₁w₂ ≠ 0 and the unit is non-degenerate (some row active, some inactive), and then sign(I) = sign(w₁w₂).

Sampled 500,000 hidden units: U(−10, 10)³, with 4% having an exact zero weight, plus 100,000 integer-weight units so that rows fall exactly on the fold. Non-degenerate: 208,906 (94,845 same-sign, 114,061 opposite-sign); exceptions: **0**. Degenerate units with I ≠ 0: **0**.

**Sigmoid (used in (e)).** σ is convex below 0 and concave above, and φ(m + d) + φ(m − d) is increasing in d when m < 0 and decreasing when m > 0. So for a sigmoid unit **sign(I) = sign(w₁w₂) · sign(−a(½, ½))**, and I = 0 iff w₁w₂ = 0 or a(½, ½) = 0. Checked on 458,744 units: 0 exceptions.

**Rescaling decides whether straight lines work (ReLU).** ReLU rescaling is a free choice of gauge, and the straight line depends on it. With the hidden vector at unit length, about a third of within-family straight paths fail. With **|u| = 1** they all work, and this can be proved. In canonical orientation u is then the constant −1 (count) or +1 (difference) along the line, so z_r(t) = s_r(t) ± ReLU(a_r(t)) with s_r and a_r linear in t. *Count* (u = −1): a₀₀ = b < 0 and a₁₁ > 0 at both ends of every non-degenerate solution, so z₀₀ and z₁₁ are linear in t and keep their sign; z₁₀ and z₀₁ are concave (linear minus convex), positive at both ends, hence positive throughout. *Difference* (u = +1): a₁₀ < 0 < a₀₁ at both ends, so z₁₀ and z₀₁ are linear; z₀₀ and z₁₁ are convex, negative at both ends, hence negative throughout. ## (d) Sigmoid twins

The map (w, b) → (−w, −b), u → −u, c → c + u gives z′ = s + u + (−u)σ(−a) = s + u − u(1 − σ(a)) = s + u σ(a) = z, an identity in x. Checked on 6,000 sigmoid solutions at 7,181 points (5000 in [−10, 10]², 500 in [−10³, 10³]², a 41 × 41 grid on [−0.5, 1.5]²): max |z − z′| = 9.31e-10, max |z − z′| / (|u| + |c| + 1) = 2.0e-13 (float rounding). The twin also solves XOR for 100.00% of them. ReLU has no such symmetry: the same map keeps XOR on the data for only 0.00% of ReLU solutions.

## (f) The h/z transposition

The transposition swaps (w₁, w₂, b) with (v₁, v₂, c): the new network is z′ = a(x) + u′ ReLU(s(x)), where a and s are the original hidden pre-activation and skip score. u′ is free. For each solution the exact set of u′ that works is an interval, the intersection of one half-line per row.

**Derivation.** Use canonical orientation. *Count family* (w > 0, u < 0): rows 10 and 01 need s > 0, because u h ≤ 0 can only lower them. Row 11 has a₁₁ > 0 (the largest pre-activation), so z′₁₁ < 0 needs u′ < 0 and s₁₁ > 0; then z′₁₀ > 0 and z′₀₁ > 0 need a₁₀, a₀₁ > 0, so the hinge is in the 3-row (OR) cell, and u′ must satisfy a₁₁/s₁₁ < |u′| < min(a₁₀/s₁₀, a₀₁/s₀₁). The original network needs s₁₁ < |u| a₁₁ and s₁₀ > |u| a₁₀, so a₁₁/s₁₁ > 1/|u| > a₁₀/s₁₀: the interval is empty. **The transposition never works in the count family.** *Difference family* (w₁ < 0 < w₂, u > 0): rows 00 and 11 need s < 0, so s₁₀ + s₀₁ = s₀₀ + s₁₁ < 0 and the transposed hinge ReLU(s) is silent on 00 and 11. Then z′₀₀ = a₀₀ and z′₁₁ = a₁₁ must be negative, so the original hinge is silent on 00 and 11: since a₀₁ is the largest and a₁₀ the smallest pre-activation, its active set is exactly {01}, the 1-row cell. Then z′₁₀ = a₁₀ + u′ s₁₀ with a₁₀ < 0 and s₁₀ = z₁₀ > 0, so **the transposition works iff the solution is in the 1-row difference cell, for every u′ > −a(r⁺)/s(r⁺)**, where r⁺ is the positive row on which the original hinge is silent (10 in this orientation). The transposed network is again a 1-row difference solution. The threshold scales with the original network's weights, including under ReLU rescaling, so it is not a constant.
