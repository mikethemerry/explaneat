# Figures: 10-seed consistency experiment (thesis Ch 7)

Generated by `experiments/10seed/make_figures.py` from the run and explanation CSVs; regenerate with

```bash
uv run python experiments/10seed/make_figures.py
```

Each figure is saved as PDF (vector, for the thesis) and PNG (300 dpi). No titles are baked
in; the captions below are drafts for the thesis. Files ending `_prereg` show the
pre-registered datasets (Heart 40 generations, MONK-2, Adult). Files ending `_supp` show the
additional analyses that were **not pre-registered** (Heart-100, churn100, churn200) and must be
captioned as such. In every strip plot each dot is one seed (10 per dataset), with horizontal
jitter only; the box spans the IQR, the thick line is the median and the whiskers span
min–max.

## `structure_prereg` and `structure_supp`

**Draft caption (prereg):** Structure of the best genome of each of the 10 seeds per
dataset. Panels: hidden nodes; enabled phenotype connections; depth (longest input→output
path, in edges); skip connections (enabled edges whose target depth exceeds the source depth
by more than 1, excluding direct input→output edges); direct input→output edges; and the
structural monosemanticity proxy (share of hidden nodes with at most two distinct original
input features upstream; a structural proxy, not an annotation result). Open diamonds: the
paper's network for that dataset (a reference, not one of the 10 seeds).

**Draft caption (supp):** As the structure figure, for the additional analyses (not
pre-registered): Heart trained for 100 generations, and churn at 100 and 200 generations.
There is no paper network for these.

## `cost_prereg` and `cost_supp`

**Draft caption:** Cost per run. Left: training wall clock in hours (one process per seed,
one CPU thread, Apple M4 Pro). Right: Claude-assisted explanation wall clock in minutes, from the
`start` to the `end` time in each `explanations/<label>.json` record (3-hour box per network).

Notes for the caption or text:
- Adult training time is **net of suspensions**: the 42.46 h pause and the per-seed throttle
  intervals in `RUN_INCIDENTS.md` are subtracted from the raw end-minus-start time. Raw
  times are about 47 h and are in `runs.csv` and `summary.md`.
- Heart (40 generations) ran on the code before `9259bf1`, whose slow per-genome DB lookups
  (about 73 s per generation) dominate its 3.5 h. Heart-100, MONK-2 and churn ran on the
  faster code, which gives bit-identical results. So Heart's time is not comparable with the others.
- MONK-2 and Adult explanation agents shared the CPU with training runs.

## `test_auc_prereg` and `test_auc_supp`

**Draft caption (prereg):** Test AUC of the best (training-fitness) genome of each seed, with
95% paired bootstrap CIs (10,000 resamples of the test set, seed 42). P: the paper network.
Dashed: the paper's L2 logistic-regression test AUC on the same split (Heart 0.919, MONK-2
0.423, Adult 0.905). Dotted (Adult only): gradient boosting ≈ 0.930. This value comes from a
PMLB 80:20 screen on a comparable encoding, **not the paper split**, so it is approximate
(`results/10seed-consistency.md` §7). No GBM baseline on the paper split is available for
Heart or MONK-2. Heart's test set has n = 61, hence the wide CIs.

**Draft caption (supp):** As the test-AUC figure, for the additional analyses (not
pre-registered). Heart-100 uses the Heart LR baseline. For churn, both baselines come from the
same split (`experiments/churn/baselines.json`): L2 logistic regression 0.813, gradient boosting 0.932.

## `coverage_time`

**Draft caption:** Coverage reached by each network against the time taken to explain it.
Each dot is one network, placed at its Claude explanation wall clock. A filled dot means full
coverage: tool structural and compositional coverage both 1.0, and a single root annotation
whose subgraph contains the output, with every annotation beneath it. A hollow dot would mean
not explained within budget; there are none. The dashed line is the pre-registered 3-hour box.
(a) The pre-registered datasets. (b) The additional analyses, not pre-registered. All 60
networks reached full coverage within the box. These are Claude-assisted explanations, re-checked
independently by script. **None has been verified by Mike yet.**
