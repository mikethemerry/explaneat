# Chapter 7, Experiment 1: tables, figures and the network appendix

Generated files carry a "Generated by <script>" header. The database is only read, in READ ONLY
transactions (`PGOPTIONS=-c default_transaction_read_only=on`); never run `explaneat setup` or migrations
against `explaneat_dev`. Run order below; `thesis/scripts/reproduce_ch7.sh` runs the same commands.

PGOPTIONS='-c default_transaction_read_only=on' DATABASE_URL=postgresql://localhost/explaneat_dev \

## The appendix (`appendix_networks.tex`, `\label{app:exp1-networks}`)

One subsection per case, in this order: Adult, Heart, MONK-2 (original networks), Churn (seed 10),
Connect-4 cells (seed 1), Connect-4 lines (seed 0), Synthetic U
(seed 0), saddle (seed 0), U and saddle (seed 4), XOR. A case's heading is on a right-hand page; a network with
hidden units then has its raw figure on the left page and the explained figure facing it. The survival networks
(WHAS500, GBSG2) are not here: they move to Chapter 8. Connect-4 cells has the explained figure only
(its raw network, 472 connections, is not legible on a page); XOR has one figure of the two minimal reduced
networks (count and difference family). Both Connect-4 explained figures are collapsed (each top-level part
one box). The annotation of unconnected inputs that sits outside the root
(Adult, MONK-2: decision D4) is drawn as a dashed box beside the explained network. Drawing code:
`thesis/ch7/netfigs.py` (`build_appendix`: any list of networks, output folder and label prefix; shared with Experiment 2) and `explaneat/export/render_structure.py`.

PDF determinism: the network PDFs are recompiled only when the hash of their TikZ source changes
(`figures/exp1/networks/sources.json`), so a rerun leaves them untouched; the matplotlib figures are saved
without creation or modification dates (figlib.save), so a rerun gives byte-identical PDFs.

## Connect-4 layer files (not committed)

The plain-language layers of the two Connect-4 networks are too large to commit
(`experiments/c4_capacity/plain_language/c4cap-main-h10-e50-s1.json`, ~24 MB, and
`experiments/c4_line_features/plain_language/c4lf-lines-heavy-s0.json`, ~10 MB). Their appendix
figures and `appendix_networks.tex` are committed. Without the layers, `networks.py` keeps the
committed outputs and prints the commands to regenerate them (read-only extraction, ~3 h and
~20 min; the same commands are in `REGENERATE` in `networks.py`).
