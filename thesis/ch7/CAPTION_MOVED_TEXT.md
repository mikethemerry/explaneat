# Chapter 7: text moved out of the table and figure captions (20 Nov 2026)

Mike's rule (20 Nov 2026): a caption holds only (1) a short title and (2) the keys needed to read the
table or figure (what bold, ✓, w, letters, daggers, brackets, -- and shading mean; units or the metric
when not in the header; footnote markers). Methodology and results presentation belong in the body
text, which Mike writes.

For every table and figure float in the Overleaf upload (`thesis/scripts/build_overleaf_upload.sh`),
plus `exp2-runs-*`, `exp2-headline` and the Experiment 2 figure floats, this file gives the old caption
(verbatim, as generated before the change), the new caption, and the removed sentences grouped as
**methodology** and **results**. Square brackets mark context added here so a fragment reads on its
own, and the source file of a number where it is not obvious; the numbers are as the generators printed
them on 20 Nov 2026 (rerun the generators before quoting, see `thesis/ch7/PROVENANCE.md`).

The appendix network captions (`thesis/ch7/exp2/appendix_networks.tex`, `networks.py`) were already a
title only ("Adult, seed 0: the network as trained, before any explanation." / "... the explained
network, every unit nested by part.") and are unchanged.

Generated once by a one-off script from the old and new `.tex`; not regenerated by `reproduce_ch7.sh`.
