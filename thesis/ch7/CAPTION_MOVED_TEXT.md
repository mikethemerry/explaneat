# Chapter 7: text moved out of the table and figure captions (20 Nov 2026)

Mike's rule (20 Nov 2026): a caption holds only (1) a short title and (2) the keys needed to read the
table or figure (what bold, ✓, w, letters, daggers, brackets, -- and shading mean; units or the metric
when not in the header; footnote markers). Methodology and results presentation belong in the body
text, which Mike writes.

For every table and figure float in the Overleaf upload (`thesis/scripts/build_overleaf_upload.sh`),
plus `exp2-runs-*`, `exp2-headline` and the Experiment 2 figure floats, this file gives the old caption
(verbatim, as generated before the change), the new caption, and the removed sentences grouped as
**methodology** and **results**. Square brackets mark context added here so a fragment reads on its
own, and the source file of a number where it is not obvious; the numbers are as the generators printed
them on 20 Nov 2026 (rerun the generators before quoting, see `thesis/ch7/PROVENANCE.md`).

The appendix network captions (`thesis/ch7/exp2/appendix_networks.tex`, `networks.py`) were already a
title only ("Adult, seed 0: the network as trained, before any explanation." / "... the explained
network, every unit nested by part.") and are unchanged.

Generated once by a one-off script from the old and new `.tex`; not regenerated by `reproduce_ch7.sh`.

**Not in the captions: methodology (for the body text)**

- Datasets: Churn and the three synthetic sets (U, saddle, U + saddle). Adult and Connect-4 are left out on
  compute grounds.
- Factors, full factorial (twelve configurations): backprop epochs per generation (5, 20); structural-mutation

  coefficient 1; Adult/Churn: 0.7/0.1, 0.68/0.15, 5, 2); weight decay, the L2 penalty of the per-genome

  100 generations, AUC fitness, ReLU hidden and sigmoid output units, fully connected direct start, unmasked
  backprop). The fixed configuration is 5 epochs, no decay, with the Adult/Churn family for Churn and the
  Heart family for the synthetic sets.
- Selection: 5-fold stratified cross-validation on the training rows only (shuffled, seed 42; the comparator
  suite's splitter); per configuration and fold one run (seed 0) trained on four folds, its best genome by
  training AUC scored on the held-out fold; the configuration with the highest mean fold AUC is chosen, means
  equal at three decimals count as tied and the simplest wins (fewer epochs, then lower decay, then the Heart
  family). On Synth. U this tie rule decided between two configurations.
- The chosen configuration is trained on all training rows with seeds 0--4 and each run's test AUC is read
  once; the fixed column is seeds 0--4 of the existing fixed runs, from their run records (Churn has ten
  fixed seeds; the table uses 0--4). The comparators are the Experiment 1 and 2 suite on the same split.
- Running the fixed configuration through the same in-memory harness reproduces each fixed seed-0 run exactly.
