```python
"""Connect-4 bitboard engine (Pons' layout), numba-jitted. 7 columns x 6 rows; column c holds
bits c*7..c*7+5 (bit c*7+6 is a sentinel). ``pos`` = stones of the side to move, ``mask`` = all stones."""
import numpy as np
from numba import njit

W, H = 7, 6
BOTTOM = np.uint64(sum(1 << (c * 7) for c in range(W)))
BOARD = np.uint64(BOTTOM * np.uint64((1 << H) - 1))

@njit(cache=True)
def bottom_mask(c): return np.uint64(1) << np.uint64(c * 7)
@njit(cache=True)
def top_mask(c): return np.uint64(1) << np.uint64(c * 7 + 5)
@njit(cache=True)
def column_mask(c): return np.uint64(63) << np.uint64(c * 7)

@njit(cache=True)
def can_play(mask, c):
    return (np.uint64(mask) & top_mask(c)) == 0

@njit(cache=True)
def play(pos, mask, c):
    pos, mask = np.uint64(pos), np.uint64(mask)
    new_pos = pos ^ mask
    new_mask = mask | (mask + bottom_mask(c))
    return new_pos, new_mask

@njit(cache=True)
def has_won(p):
    p = np.uint64(p)
    for s in (1, 7, 6, 8):
        sh = np.uint64(s)
        m = p & (p >> sh)
        if m & (m >> np.uint64(2 * s)):
            return True
    return False

@njit(cache=True)
def is_winning_move(pos, mask, c):
    pos, mask = np.uint64(pos), np.uint64(mask)
    p = pos | ((mask + bottom_mask(c)) & column_mask(c))
    return has_won(p)

@njit(cache=True)
def n_moves(mask):
    m, n = np.uint64(mask), 0
    while m:
        m &= m - np.uint64(1)
        n += 1
    return n

def legal_moves(mask):
    return np.array([c for c in range(W) if can_play(mask, c)], dtype=np.int64)

@njit(cache=True)
def encode_into(pos, mask, out):
    pos, mask = np.uint64(pos), np.uint64(mask)
    opp = pos ^ mask
    for c in range(W):
        for r in range(H):
            b = np.uint64(1) << np.uint64(c * 7 + r)
            out[c * 6 + r] = 1.0 if pos & b else (-1.0 if opp & b else 0.0)

def encode(pos, mask):
    out = np.zeros(42)
    encode_into(pos, mask, out)
    return out

def from_cells(v):
    pos = mask = 0
    for c in range(W):
        for r in range(H):
            b = 1 << (c * 7 + r)
            if v[c * 6 + r] != 0:
                mask |= b
            if v[c * 6 + r] == 1:
                pos |= b
    return np.uint64(pos), np.uint64(mask)
```

(Return types: keep `pos`/`mask` as `np.uint64` everywhere. Python ints compare equal to them, so the tests' `==` works.)

### Task 2: Solver wrapper and UCI check

**Files:**
- Create: `experiments/c4_selfplay/solver.py`
- Test: `experiments/c4_selfplay/tests/test_solver.py`

Pons' binary reads one move sequence per line on stdin (columns `1`-`7`) and prints `<seq> <score> <nodes> <µs>`. The score is from the side to move: `>0` win, `0` draw, `<0` loss. With `-a` it prints 7 scores, one per column, with `-1000` for an unplayable column. It prints "Unable to load opening book" on stderr; ignore that.

API:
- `SOLVER = Path(os.environ.get("C4_SOLVER", "~/.explaneat/tools/pons_connect4/c4solver")).expanduser()`
- `board_to_seq(cells_x_view: np.ndarray[42]) -> str`: backtracking, gravity plus alternation, x first (the existing scratch version is in the session; copy its `to_seq`). Raise if no order exists.
- `seq_of_game(moves: list[int]) -> str`: 0-based columns to the solver string.
- `solve(seqs: list[str], analyse=False, workers=12, chunk=64) -> np.ndarray`: split into chunks, run one `c4solver` subprocess per chunk through `concurrent.futures.ThreadPoolExecutor(workers)`, and keep the input order. It returns `[n]` scores, or `[n, 7]` with `analyse=True`.
- `solve_cached(seqs, path, analyse=False)`: a csv cache keyed by sequence (`seq,score` or `seq,s0..s6`). It solves only the missing ones and appends them.

### Task 4: Batched value-only MCTS

**Files:**
- Create: `experiments/c4_selfplay/mcts.py`
- Test: `experiments/c4_selfplay/tests/test_mcts.py`

Design. Value convention: a node's value is P(win) for **the side to move at that node**.

- `Node`: `pos, mask, terminal_value (None | 0.0 | 0.5)`, `children: dict[col, Node]`, `N`, `W` (sum of values from the **parent's** mover's view), `expanded`.
- Terminal check on creation: if the move into this node won, the side to move here has lost, so the value is 0.0. If the board is full (42 stones), 0.5.
- **Immediate-win shortcut** (cheap and important for strength): at expansion, if a legal move wins at once, only that child exists.
- `select(node)`: UCB = `Q + c_puct * sqrt(node.N) / (1 + child.N)`, uniform priors, `Q = child.W / child.N` (0.5 when unvisited), `c_puct = 1.5`. Break ties by lowest column.
- `run_batch(roots: list[Node], value_fn, n_sims, rng, dirichlet=None)`: for each simulation step, descend every root to a leaf.
  - A terminal leaf backs up its exact value.
  - Non-terminal leaves are encoded into one array `[k, 42]` and evaluated with one `value_fn` call, expanded, and backed up with the value flipped per level (`v -> 1 - v`).
- `policy(root, temperature)`: visit counts to a probability vector over 7 columns. Temperature 0 means argmax, ties to lowest column.

### Task 5: Fixed opponents

**Files:**
- Create: `experiments/c4_selfplay/opponents.py`
- Test: `experiments/c4_selfplay/tests/test_opponents.py`

Every player is `choose(pos, mask, rng) -> col`, plus a batched `choose_many(states, rng) -> cols`.
- `RandomPlayer`.
- `AlphaBeta(depth)`: numba negamax.
  - Leaf heuristic 0; a win scores `+(43 - n_moves)`.
  - Columns are tried centre first; among equally best moves, pick uniformly with the given rng, so seeded games are reproducible.
- `SolverPlayer`: `solver.solve([seq], analyse=True)`, takes the best-scoring column, ties to centre. It is slow on early positions, so use it only for the top ladder rung and cache by sequence.
- `NetGreedy(value_fn)`: one ply. For each legal move, take a win at once, else score it as `1 - value_fn(child)`, and take the argmax.
- `NetMCTS(value_fn, n_sims)`: wraps `mcts.run_batch`, temperature 0.
- `play_match(a, b, openings, rng) -> list[dict]`: each opening (a short move sequence) is played twice, once with each side first. It records the result from a's view (1 / 0.5 / 0), the move count and the move list.

**Tests:**

- `AlphaBeta(2)` takes an immediate win;
- `play_match` is deterministic for a fixed seed.

### Task 6: Self-play games and replay buffer

**Files:**
- Create: `experiments/c4_selfplay/selfplay.py`
- Test: `experiments/c4_selfplay/tests/test_selfplay.py`

API:
- `play_games(value_fn, n_games, n_sims, rng, temp_moves=8, dirichlet_eps=0.0) -> (X [m,42], y [m], games)`. All `n_games` run in lockstep through `mcts.run_batch`, one new tree per move (no tree reuse: simpler, and fine at 200 sims). For the first `temp_moves` moves, sample from the visit counts with temperature 1; after that, argmax. Each position is labelled from its side to move: 1 if that side won, 0 if it lost, 0.5 for a draw.
- `ReplayBuffer(max_rounds)`: `add(round, X, y)`, then `data()` deduplicates identical positions by mean label over the last `max_rounds` rounds and returns `(X, y)`.

**Tests:**
- labels flip between consecutive positions in a decisive game;
- a drawn game is all 0.5;
- deduplication averages labels;
- old rounds drop out.

### Task 7: The round loop

**Files:**
- Create: `experiments/c4_selfplay/run.py`

Behaviour (`PYTHONHASHSEED=0 uv run python experiments/c4_selfplay/run.py --name <n> --seed 0 --rounds R --games N --sims S --gens G --epochs E --buffer K`):
1. Refuse to run without `PYTHONHASHSEED=0`. Set `EXPLANEAT_DEVICE=cpu`. Call `seed_everything(seed)` (copy it from `experiments/complex_real/run_seed.py`: random, numpy, torch, `set_num_threads`, deterministic algorithms).
2. Round 0's player is `ConstValue(0.5)` with MCTS (random-ish play that still takes wins and blocks).
3. Each round `r`:
   - self-play with the current champion;
   - add to the buffer;
   - set `pop.xs`, `pop.ys` to the buffer as float64 tensors (`ys` shaped `[n, 1]`);
   - set `pop.best_genome = None`;
   - run `pop.run(neg_bce_fitness, n=G, nEpochs=E)`;
   - the champion becomes `pop.best_genome` (the best fitness within this round; fitness across rounds isn't comparable because the buffer changes).
4. The population is created **once**, with `BackpropPopulation(config, X0, y0, mask_phantom=True, skip_invalid_genomes=True)`, using round 0's data. `neat.Population` keeps its `generation` counter across `run` calls, so the lineage is continuous.
5. Fitness `neg_bce_fitness(genomes, config, xs, ys, device)`: for each genome, `NeuralNeat(...)`, then fitness `= -BCE(pred, ys)`. An invalid genome gets `-1e9`. (The soft 0.5 labels rule out AUC.)
6. Every generation, append `{generation: {key: genome}}` for the whole population to `~/.explaneat/c4_selfplay_runs/<name>/genomes_r<round>.pkl.gz`, one file per round.    - `meta.json` (args, commit, config text).
8. Checkpoint after each round (pickle the population state, RNG states and buffer) so a killed run resumes. Follow the pattern in `experiments/c4_capacity/run_seed.py:186-205`.
